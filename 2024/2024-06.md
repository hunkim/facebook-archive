### 6월 30일 (일) 20:37 · 제가 매일 사용하는 #solarllm 을 활용하여 생산성을 올려줄수 있는…

제가 매일 사용하는 #solarllm 을 활용하여 생산성을 올려줄수 있는 툴 하나 소개 드립니다. https://harpa.ai/ 크롬의 plugin 인데요. 요약, 페이지 질문답변, 번역, 글쓰기, 이메일 답장, 비디오 요약등 단편적인 작업을 할수 있습니다. 또한 이런 2~3개의 작업을 붙여 자동으로도 할수 있습니다. 

예를 아래 첫 스크린샷 처럼 웹페이지나 블로그 글등을 (특히 영어나 외국어) 읽을때 한번 요약을 보고, 필요하면 더 자세히 볼수 있습니다. 

harpa에 LLM을 지정할수 있는데요. #solarllm을 사용하면 정말 빠르게 원하는 결과를 얻을수 있습니다. 언어 설정을 한국어로 해두시면 한국어 답변/을 받을수 있습니다. 세팅을 위해서는 Upstage API키를 https://console.upstage.ai/ 에서 받으신 다음, 모델 이름은 solar-1-mini-chat, api proxy url은 https://api.upstage.ai 로 지정하면 됩니다. (2번째 스샷 참고) 

참고로 https://predibase.com/blog/solar-llm-on-predibase-the-best-llm-for-fine-tuning 의 내용 요약을 보면 더 빠르게 이해 가능합니다.

- 🌞 [Solar LLM on Predibase 소개](https://predibase.com/blog/solar-llm-on-predibase-the-best-llm-for-fine-tuning): GPT-4를 능가하는 미세 조정용 최고의 LLM
- 📈 [Solar LLM의 성능](https://arxiv.org/abs/2405.00732): Upstage의 Solar LLM은 ~11B 매개 변수 모델 무게 클래스에서 가장 우수한 성능을 발휘합니다.
- 💡 [미세 조정을 위한 최적의 모델](https://predibase.com/fine-tuning-index): Solar LLM은 Upstage의 실험에서 31개 작업 중 16개에서 최고 점수를 획득하여 가장 우수한 성능을 발휘했습니다.
- 🚀 [Predibase의 미세 조정 기술](https://predibase.com/fine-tuning-index): Predibase는 빠르고 안정적이며 비용 효율적인 LLM 미세 조정을 위한 선도적인 개발자 플랫폼입니다.
