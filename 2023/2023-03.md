### 3월 2일 (목) 09:02 · openai의 chatgpt api가 공개 되었습니다. 그동안 3.5의 …

openai의 chatgpt api가 공개 되었습니다. 그동안 3.5의 completion과는 다른 형태로 1. 명시적으로 instruction을 주는 형식으로 입력을 받고 (help instruct the assistant), 2. 대화 기록 (conversation history) 을 통해 이전 context를 더 명확하게 가지게 될것 같습니다. 

재미있는 어플리케이션들이 많이 나올것 같습니다.
(아쉽게도 아직 finetuning은 제공하지 않는것 같습니다.)

https://platform.openai.com/docs/guides/chat/introduction

(저희 AskUp도 위 1, 2를 활용하면 성능이 엄청 올라갈것 같습니다. 코드 완전 수정해서 정식 릴리즈 하겠습니다: https://m.khan.co.kr/economy/economy-general/article/202302141627001)

**이미지 캡션:** 이 이미지는 프로그래밍 코드와 그에 대한 설명을 보여줍니다. 코드 부분은 검은색 배경에 흰색 글씨로 작성된 파이썬 코드 스니펫으로, OpenAI 라이브러리를 사용하여 챗봇과 상호작용하는 방법을 보여줍니다. 코드에는 `import openai`, `openai.ChatCompletion.create`와 같은 함수 호출, 그리고 `model="gpt-3.5-turbo"`와 같은 매개변수가 포함되어 있습니다. 또한, 시스템 메시지, 사용자 메시지, 어시스턴트 메시지를 포함하는 `messages` 배열이 정의되어 있으며, 이는 챗봇과의 대화 기록을 나타냅니다. 예를 들어, "You are a helpful assistant."라는 시스템 메시지와 "Who won the world series in 2020?"라는 사용자 메시지, 그리고 "The Los Angeles Dodgers won the World"라는 어시스턴트 메시지가 보입니다. 코드 아래에는 이 코드를 설명하는 텍스트가 흰색 배경에 검은색 글씨로 작성되어 있습니다. 이 텍스트는 `messages` 매개변수의 역할, 메시지 객체의 구조(role과 content), 대화 형식, 시스템 메시지, 사용자 메시지, 어시스턴트 메시지의 기능, 그리고 대화 기록의 중요성에 대해 설명합니다. 전반적으로 이 이미지는 프로그래밍 교육 자료의 일부로 보이며, 챗봇 API 사용법을 설명하는 데 중점을 두고 있습니다.
